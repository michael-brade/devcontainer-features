# devcontainer-features

Settings I want for my devcontainers.

- essential-tools:
  Make sure everyday tools like git, htop less, source-highlight, nvim are available.

- bash-aliases:
  This enabled bash autocompletion, enables colors in ls and grep and adds a few bash and git aliases.
  It also sets up less for highlighting.
